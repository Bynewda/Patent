# 리담 변리사 2차 아카데미 (예시 사이트)

변리사 **2차 시험(논술형)** 대비용 정적 웹사이트 **예시**입니다.
참고하신 사이트는 **1차(객관식)** 대비 구조이므로, 같은 학원 콘셉트를 **2차(논술·사례형)** 학습 흐름에 맞게 다시 설계했습니다.
설치 없이 브라우저에서 바로 열 수 있는 순수 HTML / CSS / 바닐라 JavaScript (A안) 로 만들었습니다.

> ⚠️ 이 사이트의 문제·모범답안·판례·일정·과목 구성은 모두 **학습용 예시(데모)** 이며 실제 기출·공식 정보가 아닙니다.

---

## 1. 1차용과 2차용은 무엇이 다른가 (설계 방법)

핵심은 **시험 형태가 다르면 '학습 흐름'이 달라지고, 학습 흐름이 달라지면 사이트의 화면과 기능도 달라져야 한다**는 점입니다.

| 구분 | 1차 (객관식) | 2차 (논술·사례형) · 이 사이트 |
| --- | --- | --- |
| 과목 | 산업재산권법, 민법개론, 자연과학개론 | 특허법, 상표법, 민사소송법, 선택과목 |
| 시험 형태 | 객관식 (정답 선택) | 논술형·사례형 (답안 서술) |
| 학습 흐름 | 문제은행 → 퀴즈 → **자동 채점** → 오답노트 | 쟁점 정리 → **답안 작성** → 모범답안 비교 → **첨삭** |
| 핵심 기능 | 보기 선택, 즉시 채점, 정답률 통계 | 사례형 문제 뷰어, 답안 작성 에디터, 모범답안 토글, 첨삭 신청 |
| 화면(UI) 성격 | 빠른 반복, 대시보드·통계 중심 | 긴 글 가독성, 작성 공간, 비교 뷰, 피드백 흐름 중심 |

### 1차용 사이트를 2차용으로 바꾸는 방법 (단계별)

1. **과목을 교체한다.** 메뉴/페이지를 산업재산권법·민법개론·자연과학개론 → 특허법·상표법·민사소송법·선택과목으로 바꿉니다.
2. **중심 기능을 '채점'에서 '작성·첨삭'으로 바꾼다.**
   - 객관식 퀴즈/자동 채점 화면을 제거하고,
   - **사례형·논술형 문제 뷰어**(쟁점 보기 + 모범답안 토글)와 **답안 작성 → 첨삭 신청** 흐름을 중심에 둡니다.
3. **콘텐츠 단위를 바꾼다.** "문항 + 보기 + 정답" 대신 "문제 + **쟁점(논점) 목록** + **모범답안(목차형 서술)**" 구조로 저장/표시합니다.
4. **디자인 톤을 조정한다.** 긴 글을 오래 읽고 쓰는 공부이므로, 넉넉한 줄 간격·차분한 색·높은 가독성 위주로 설계합니다. (이 사이트는 딥그린 계열 + 밝은 배경을 사용)
5. **보조 기능을 맞춘다.** 오답노트 대신 **판례·조문 정리, 모의고사 일정, 스터디 모집** 같은 2차 특화 자료를 둡니다.

이 예시는 위 5단계를 그대로 반영해 만들었습니다.

---

## 2. 사용 방법 (열어 보기)

별도 설치·서버·빌드가 필요 없습니다.

1. 폴더를 내려받습니다.
2. **`index.html` 파일을 더블클릭**하면 기본 브라우저에서 열립니다.
3. 상단 메뉴로 모든 페이지를 이동할 수 있습니다.

> 참고: `index.html` 하단의 "제작 방법 자세히 보기(README)" 링크는 이 문서를 가리킵니다.
> 구글 폰트(Noto Sans KR)는 인터넷 연결 시 자동 적용되며, 오프라인이어도 시스템 한글 폰트로 정상 표시됩니다.

### 주요 화면

- **홈 (`index.html`)** — 2차 대비 과정 소개, 과목 바로가기, 1차 vs 2차 비교.
- **과목별 강의 (`subjects/`)** — `patent.html`(특허법), `trademark.html`(상표법), `civil-procedure.html`(민사소송법), `elective.html`(선택과목). 각 과목의 논술·사례형 중심 커리큘럼 예시.
- **사례·논술 문제 (`problems.html`)** — 문제를 읽고 **[쟁점 보기]** / **[모범답안 보기]** 버튼으로 내용을 펼쳐 비교합니다.
- **답안 첨삭 신청 (`submit.html`)** — 답안을 작성(글자 수 카운터 포함)하고 제출하면 접수 확인 메시지가 표시됩니다. 백엔드가 없으므로 실제 전송 없이 브라우저 안에서만 동작합니다.
- **판례·일정 (`resources.html`)** — 주요 판례·조문 정리, 모의고사 일정, 스터디 모집 예시.

## 3. 폴더 구조

```
/
├── index.html                  홈 (랜딩)
├── problems.html               사례·논술 문제 뷰어 (쟁점/모범답안 토글)
├── submit.html                 답안 작성 → 첨삭 신청 폼
├── resources.html              판례·조문·모의고사·스터디
├── subjects/
│   ├── patent.html             특허법
│   ├── trademark.html          상표법
│   ├── civil-procedure.html    민사소송법
│   └── elective.html           선택과목
├── css/
│   └── style.css               공통 스타일 (반응형, 차분한 가독성 톤)
├── js/
│   ├── main.js                 내비 토글, 쟁점/모범답안 토글
│   └── submit.js               첨삭 신청 폼 처리, 글자 수 카운터
└── README.md                   이 문서
```

---

## 4. 직접 콘텐츠를 바꾸는 방법

- **문제·쟁점·모범답안 추가:** `problems.html`의 `<article class="qa-card">` 블록을 복사해 내용을 바꿉니다.
  쟁점 패널(`#issues-...`)과 모범답안 패널(`#answer-...`)의 `id`를 문제마다 고유하게 지정하고, 버튼의 `data-toggle-target`을 같은 `id`로 맞추면 토글이 동작합니다.
- **과목 커리큘럼 수정:** `subjects/*.html`의 `<ol class="curriculum">` 항목을 편집합니다.
- **색상·톤 변경:** `css/style.css` 상단 `:root`의 CSS 변수(`--color-primary` 등)만 바꾸면 전체 테마가 바뀝니다.

---

이 예시는 변리사 2차 대비 사이트의 **구조와 학습 흐름**을 보여주기 위한 데모입니다.
실제 서비스로 확장할 때는 답안 저장·강사 첨삭·회원 기능을 위한 백엔드를 추가하면 됩니다.
